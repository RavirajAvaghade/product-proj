# 🛒 Products Management System

## 📌 Project Overview

The **Products Management System** is a dynamic web-based application developed using **HTML, CSS, JSP, Servlets, and JDBC**.
This project allows users to **add (insert) products** and **view stored product details** from a database.

It demonstrates the integration of frontend and backend technologies to perform basic **CRUD operations (Create & Read)**.

---

## 🚀 Features

* ➕ Add new products
* 📋 View all products
* 💾 Store product data in database
* 🔄 Dynamic data handling using JSP & Servlets
* 🔗 Database connectivity using JDBC

---

## 🛠️ Technologies Used

* 🌐 **HTML** – Structure of web pages
* 🎨 **CSS** – Styling and layout
* ⚙️ **JSP (Java Server Pages)** – Dynamic content rendering
* 🔧 **Servlets** – Backend processing
* 🗄️ **JDBC** – Database connectivity
* 🛢️ **MySQL / Oracle (any DB you used)**

---

## ⚙️ How It Works

1. User opens the application
2. Adds product details using form
3. Data is sent to Servlet
4. Servlet uses JDBC to store data in database
5. Products can be viewed dynamically using JSP

---

## 🖥️ Setup Instructions

1. Install **Apache Tomcat Server**
2. Install **MySQL / any database**
3. Import project into IDE (Eclipse / IntelliJ)
4. Configure database connection in JDBC
5. Deploy project on Tomcat server
6. Run the application in browser
